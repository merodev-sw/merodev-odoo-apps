Inventory Access Control

Secure Warehouse Access & Controlled Internal Transfers

Inventory Access Control helps companies manage warehouse permissions by assigning each user to specific warehouse locations and controlling where stock can be transferred. The module also enforces a secure two-step transfer process through a dedicated Transit location.

Key Features

  • ✔ Assign allowed warehouse locations for each user.
  • ✔ Restrict transfer destinations.
  • ✔ Prevent unauthorized warehouse transfers.
  • ✔ Enforce two-step internal transfers through a Transit location.
  • ✔ Improve inventory security and traceability.
  • ✔ Easy configuration directly from the user form.

User Configuration

Add warehouse employees to the Restricted Warehouse User group, then configure their allowed warehouse locations and allowed transfer destinations. Users will only be able to perform inventory operations within the assigned locations.

Controlled Transfer Workflow

Instead of allowing direct warehouse-to-warehouse transfers, the module enforces a secure two-step workflow using a dedicated Transit location, ensuring better stock tracking and complete transfer traceability.

How It Works

  1. Create an internal location named Transit.
  2. Assign users to the Restricted Warehouse User group.
  3. Configure each user's allowed warehouse locations.
  4. Configure the warehouses they are allowed to transfer to.
  5. Create internal transfers as usual.
  6. The module automatically enforces the transfer through the Transit location.

Benefits
